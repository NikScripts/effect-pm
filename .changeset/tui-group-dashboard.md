Shared dashboard core on `hyperlink-ts/ui` (data bundles, group route resolve, atom-react, memberKind + wireKindOf). `hyperlink-ts/web` and `hyperlink-ts/tui` are renderers over that SSOT. TUI `<Dashboard runtime group path? />` opens from `Hyperlink.cli` bare paths via the optional `Tui` service, with grid/detail cells for queue, priority, daemon, gate, api, fleetHealth, telemetry, and shardMap. Unknown/Hyperlink leaves show stamped kind + node bind.
