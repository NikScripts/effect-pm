**Lookup layers match Effect `layer` / `layerOptions`:** `Lookup.layer` is a Layer value (bind-or-dial default ipc — `Layer.provide(Lookup.layer)`). `Lookup.layerOptions({ path?, unlink? })` is the options factory. Addressed exclusive serve is `Lookup.layerNode(node)`. Dial-default path is `Lookup.clientOptions`. Removed (no shim): `bootstrapDefaultLocal`, `layerDefaultLocal`, `clientDefaultLocal`.
